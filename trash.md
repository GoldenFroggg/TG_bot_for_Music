## 📖 О проекте

Music Assistant Bot — музыкальный помощник в Telegram. Он умеет:

- находить трек по названию и исполнителю;
- показывать подробную информацию о нём;
- подбирать схожие треки, чтобы вы могли открыть для себя что-то новое.

Проект создан командой энтузиастов как способ упростить поиск и открытие музыки прямо в мессенджере, без установки дополнительных приложений.

## ✨ Возможности

- 🔎 Информация о треке — название, исполнитель, альбом, год выхода, жанр и другие данные
- 🎧 Похожие треки — рекомендации на основе выбранной композиции
- 💬 Простое общение — достаточно отправить сообщение с названием песни
- ⚡️ Быстрые ответы — результат приходит за пару секунд

## 🚀 Как пользоваться

1. Найдите бота в Telegram: [@your_bot_username](https://t.me/your_bot_username)
2. Нажмите Start или отправьте команду /start
3. Отправьте название трека, например: Daft Punk — Get Lucky
4. Получите информацию о треке и список похожих композиций

### Команды

| Команда   | Описание                               |
|-----------|----------------------------------------|
| /start  | Запустить бота и получить приветствие  |
| /help   | Список команд и подсказки по работе    |
| /track  | Найти информацию о треке               |
| /similar| Получить похожие треки                 |

> Список команд можно изменить под реальный функционал бота.

## 🛠 Технологии

- Язык: Python 3.10+
- Telegram-фреймворк: [aiogram](https://github.com/aiogram/aiogram) / [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot)
- Источник музыкальных данных: Spotify API / Last.fm API / MusicBrainz
- Хранение данных: SQLite / PostgreSQL *(если используется)*

## ⚙️ Установка и запуск

### 1. Клонируйте репозиторий

git clone https://github.com/your-username/your-repo.git
cd your-repo
### 2. Создайте виртуальное окружение и установите зависимости

python -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows

pip install -r requirements.txt
### 3. Настройте переменные окружения

Создайте файл .env в корне проекта на основе .env.example:

BOT_TOKEN=your_telegram_bot_token
MUSIC_API_KEY=your_music_api_key
MUSIC_API_SECRET=your_music_api_secret
- Токен бота можно получить у [@BotFather](https://t.me/BotFather)
- Ключи для музыкального API — в личном кабинете выбранного сервиса

### 4. Запустите бота

python main.py
