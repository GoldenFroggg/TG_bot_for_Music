О проекте
Music Assistant Bot помогает разобираться в музыке и открывать новую прямо в мессенджере, без установки дополнительных приложений.
Пользователю достаточно написать название песни или исполнителя — бот найдёт трек, покажет информацию о нём и предложит подборку схожих треков.
Возможности
🔎 Информация о треке: название, исполнитель, альбом, год выхода, жанр
🎧 Подбор похожих треков на основе выбранной композиции
💬 Простое общение: достаточно отправить сообщение с названием песни
⚡️ Быстрый ответ за пару секунд
Как пользоваться<
1. Найдите бота в Telegram и нажмите Start.
2. Отправьте название трека, например: Daft Punk — Get Lucky.
3. Получите информацию о треке и список похожих композиций.
Команды
/start — запустить бота
/help — список команд и подсказки
/author — список авторов бота
/about - описание бота
